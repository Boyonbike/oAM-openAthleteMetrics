     Plan: Add buildSyncCommands(context: SyncContext) to WasmDriverEngine

     Context

     WasmDriverEngine already has an older buildEffectiveSyncCommands +
     callBuildSyncCommands pair
     that used a binary metadata approach (WASM signature (func (result i32)),
     no input params —
     just a 16-byte header written to memory at offset 0). A TODO in the code
     notes that no driver has
     ever used this path. The new design passes a JSON-serialised SyncContext as
     input, matching
     the richer contract used by the parse functions ((func (param i32 i32) 
     (result i32))). This is a
     clean replacement since zero drivers rely on the old calling convention.

     4. WasmDriverEngine — replace callBuildSyncCommands with 
     callBuildSyncCommandsJson

     Remove the old binary-metadata private method and add:

     /**
      * Writes [jsonBytes] at memory offset 0, calls [functionName] with (0, 
     len), and reads
      * output from OUT_OFFSET. ChicoryException causes re-instantiation and 
     returns null.
      * Must be called while parseMutex is held by the caller.
      */
     private suspend fun callBuildSyncCommandsJson(
         functionName: String,
         jsonBytes: ByteArray,
     ): String? {
         val inst = instance ?: return null
         return withContext(Dispatchers.Default) {
             try {
                 val memory = inst.memory()
                 memory.write(0, jsonBytes)
                 val result = inst.export(functionName).apply(0L,
     jsonBytes.size.toLong())
                 val outLen = result[0].toInt()
                 if (outLen <= 0) null else memory.readString(OUT_OFFSET,
     outLen)
             } catch (e: ChicoryException) {
                 Timber.w(e, "WasmDriverEngine: ChicoryException in 
     $functionName — re-instantiating")
                 runCatching {
                     val wasm = loadedManifest?.parsing as?
     ParsingConfig.WasmParsing
                     if (wasm != null) instance = instantiate(wasm.wasmBytes)
                 }.onFailure { ex ->
                     Timber.e(ex, "WasmDriverEngine: re-instantiation failed — 
     clearing dead instance")
                     instance = null
                 }
                 null
             }
         }
     }

     Memory contract for driver authors:
     - Input: JSON-encoded SyncContext string starting at byte offset 0; length
     passed as second param.
     - Output: Write JSON array of { "characteristic": "...", "bytes": "..." }
     at offset 4096 (OUT_OFFSET); return byte count.
     - Signature: (func (param i32 i32) (result i32)) — same as parse exports.
