     Plan: Add Profile Tab to Settings Screen

     Context

     The app has a full UserProfile domain model (name, DOB, bio sex,
     biometrics, HR zones) backed by UserProfileRepository /
     RoomUserProfileRepository / UserProfileDao (DB schema v14), but no UI to
     view or edit it. The Settings screen currently shows one flat scrollable
     column with Appearance, Backup, Danger Zone, and (debug) Seeder tiles. The
     task adds a Profile tab alongside those existing tiles by introducing a
     two-tab segmented control (Profile | App).

     ---
     New Files

     1. ui/settings/UserProfileViewModel.kt

     @HiltViewModel
     class UserProfileViewModel @Inject constructor(
         private val repo: UserProfileRepository,
     ) : ViewModel() {

         val profile: StateFlow<UserProfile?> =
             repo.observe().stateIn(viewModelScope,
     SharingStarted.WhileSubscribed(5_000), null)

         fun updateProfile(updated: UserProfile) {
             viewModelScope.launch {
                 try { repo.upsert(updated) }
                 catch (e: Exception) { Timber.e(e, "Failed to update profile")
     }
             }
         }
     }

     No DI changes required — UserProfileRepository is already bound as
     @Singleton in DatabaseModule.

     2. ui/settings/ProfileTab.kt

     A single @Composable function:

     @Composable
     fun ProfileTab(
         profile: UserProfile?,
         onUpdate: (UserProfile) -> Unit,
         onWeightTap: () -> Unit,
     )

     State owned by this composable:
     - var editingField: ProfileField? — which text/numeric field is active
     (NAME, HEIGHT, STRIDE_LENGTH, WRIST, RMR, VO2_MAX, MAX_HR)
     - var draftText: String — live value while a text/numeric field is open
     - var showDatePicker: Boolean — controls DatePickerDialog visibility
     - var editingZone: Int? — which HR zone row (1–5) is in edit mode
     - var draftLower: String, var draftUpper: String — live bpm values while a
     zone is open

     Helper saveCurrentField() — clears editingField first (prevents
     double-save), then calls onUpdate(profile.copy(...)) with type-appropriate
     conversion (ifBlank { null } for strings, toDoubleOrNull() / toIntOrNull()
     for numerics).

     Layout — Column(verticalScroll):

     SectionHeader("Identity")
       ProfileFieldRow("Name", ...)            // editable text
       HorizontalDivider
       ProfileDateRow("Date of Birth", ...)    // opens DatePickerDialog on tap
       HorizontalDivider
       BioSexRow(...)                          // three FilterChip inline
       HorizontalDivider

     Spacer(24.dp)

     SectionHeader("Body Metrics")
       ProfileFieldRow("Height", "cm", Decimal)
       HorizontalDivider
       ProfileFieldRow("Stride Length", "cm", Decimal)
       HorizontalDivider
       ProfileFieldRow("Wrist Circumference", "mm", Decimal)
       HorizontalDivider
       ProfileFieldRow("Resting Metabolic Rate", "kcal", Decimal)
       HorizontalDivider
       ProfileFieldRow("VO₂ Max", "ml/kg/min", Decimal)
       HorizontalDivider
       ProfileFieldRow("Max HR", "bpm", Number)
       HorizontalDivider
       WeightRow(...)                          // read-only, tappable

     Spacer(24.dp)

     SectionHeader("HR Zones")
       HrZoneRow(zone=1..5, ...)

     Inline edit pattern — each ProfileFieldRow:
     - Not editing: Row(Modifier.clickable { editingField = field; draftText = 
     current }) showing label + value/"—"
     - Editing: OutlinedTextField with FocusRequester, auto-focus via
     LaunchedEffect(editingField), KeyboardActions(onDone = { saveCurrentField()
     }), onFocusChanged { if (!isFocused) saveCurrentField() }

     Date of Birth — uses Material3 DatePickerDialog +
     DatePicker(rememberDatePickerState(...)). Epoch-millis → LocalDate →
     YYYY-MM-DD string. Saves immediately on confirm.

     Biological Sex — FilterChip row (Male / Female / Other). Tap saves
     immediately.

     Weight row — read-only display. Shows profile.weightKg formatted as "XX.X 
     kg" or "—". Subtitle: "Auto-synced from daily log".
     Modifier.clickable(onClick = onWeightTap) with ripple — same tappable
     affordance as other rows.

     HR Zone rows (1–5):
     - Not editing: Row(Modifier.clickable { editingZone = zone; 
     draftLower/Upper = ... }) showing "Zone N   lower – upper bpm" (or dashes)
     - Editing: two side-by-side OutlinedTextFields for lower/upper bpm plus a
     TextButton("Done"). Saves on Done tap or focus-lost from either field.
     Merges updated HrZone into the list (remove-if-same-zone, add new, sortBy
     zone), then calls onUpdate.
